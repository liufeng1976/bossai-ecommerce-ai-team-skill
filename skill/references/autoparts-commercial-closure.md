# BossAI 汽配 AI 员工商业闭环

## 目标

把真实汽配产品资料转换为可审核、可导出、可交给视频工厂的内容资产。默认只生成草稿，不自动发布、发消息、改价、改库存或控制平台账号。

## 必须绑定的产品事实

每份交付必须明确引用选中的真实 SKU。以下字段只能来自产品资料或用户明确提供的证据：

- 品牌、产品名称和 SKU；
- 适配车型、年款、排量、发动机或底盘条件；
- OE/OEM/互换件号；
- 材料、尺寸、接口、安装位置和包装清单；
- 价格、库存状态、质保和产品链接。

字段缺失时写“待核验”，不得根据同类产品、常识或搜索摘要补造。

## 兼容性与安全红线

- 不得把“可能适配”改写为“保证适配”；
- 不得省略年款、排量、左右侧、前后轴、接口或配置差异；
- 涉及制动、转向、悬挂、安全气囊、电池、高压或承重部件时，必须提示由合格人员核验安装；
- 不得虚构认证、测试结果、寿命、节油比例、动力提升或故障解决率；
- 不得将未知价格、库存、交期、关税或退换政策写成承诺。

## 内容生产闭环

1. 读取品牌资料、模板和被选 SKU；
2. 建立“已确认事实 / 待核验字段 / 禁止表达”清单；
3. 按渠道生成内容草稿，并保持 SKU 与车型条件可追溯；
4. 人工检查兼容性、价格、库存、安全声明和平台规则；
5. 只有 `approved` 草稿才能导出内容包；
6. 只有视频类批准内容才能生成 `video-task.json`；
7. 提交视频工厂必须再次明确确认外部执行，并以真实任务 ID 和状态为准；
8. 视频生成完成不等于发布，发布仍需单独人工授权。

## 人工审核清单

- SKU 与产品名称一致；
- 车型、年款、配置和安装位置有来源；
- OE/OEM 号未混淆品牌件号；
- 图片、口播和字幕没有夸大或遗漏关键限制；
- 价格、库存和交期仍有效；
- 没有 API Key、密码、访问令牌或内部数据库字段；
- 没有声称已经发布、成交、退款或完成外部动作。

## 商业交付物

批准后的内容包至少包含 `manifest.json`、`brief.md`、`content.md`、`review.json`、`product-context.json` 和 `assets-needed.md`。视频任务额外包含 `video-task.json`。原始 AI 草稿、人工修改稿和审核记录必须分别留痕。
