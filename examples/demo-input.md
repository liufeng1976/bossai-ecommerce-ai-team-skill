# 业务

- 项目：BossAI 国内电商客服质检
- 平台：抖店、淘宝
- 客户：客服人数少、售后压力大的中小卖家
- 目标：7天验证客服质检报告和回复草稿是否能减少错误承诺
- 产品：导入客服对话，输出问题分类、风险提示和人工审核回复草稿
- 约束：不自动发送消息、不自动退款、不控制平台账号

# 机会：客服错误承诺退款和到货时间

- 描述：客服为了快速结束对话，可能未经核对直接承诺退款、补发或具体到货日期。
- 来源：历史客服对话抽样
- 证据：30段对话中有8段出现未经规则核对的承诺。
- 标签：客服、退款、物流、合规、质检

# 机会：重复问题可以沉淀为FAQ

- 描述：物流查询、退货条件和优惠规则反复出现，但没有统一知识库。
- 来源：客服主管访谈
- 证据：主管列出12个每天重复回答的问题。
- 标签：FAQ、客服、知识库、运营
